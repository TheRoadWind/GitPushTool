## 📖 简介

用于项目快速推送至Git仓库

## ✨ 特性

- 支持显示用户已创建仓库
- 支持仓库管理
- 版本号自动读取（支持 VB/C# 工程、bin\Release / bin\Debug 编译产物 exe/dll、apk/aab、Node、Maven、Gradle、Flutter、Rust、Python 等，只读不可修改）
- 打 tag 时保留 Git 仓库原有 tag
- 推送时自动更新 README 里的版本号

## 🛠️ 环境要求

- 操作系统：Windows 10 / 11
- 运行时：.NET 10.0
